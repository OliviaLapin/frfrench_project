# French Quiz – это тренажер французского языка

**Описание проекта:**

Веб-приложение для изучения французского языка в формате интерактивных квизов. Пользователи могут проходить тесты по темам, добавлять собственные карточки со словами и отслеживать статистику.

**Функциональность:**

Изучение иностранного языка, это процесс, который требует регулярного повторения и запоминания большого количества новой лексики. Многие люди начинают учить язык, но сталкиваются с типичными трудностями:

**Нет системы**
Непонятно, какие слова уже выучены, а какие нет. Повторяются уже выученные слова, вместо новых.

**Скучно** 
Обычное заучивание по спискам быстро надоедает, хочется интерактива.

**Нет обратной связи**
Невозможно проверить, действительно ли слова запомнились.

**Сложно добавлять свои слова**
Учебники дают готовые списки, но в жизни нужны другие слова. Например, специфика по работе или сленг.

**Нет мотивации**
Без статистики и прогресса интерес быстро угасает

Fr-Fr-French решает все эти проблемы!

### Запуск проекта

Cоздать и активировать виртуальное окружение:
```python
source venv/bin/activate
```
Выполнить миграции:
```python
python3 manage.py migrate
```
Создать суперпользователя (если необходимо):
```python
python manage.py createsuperuser
```
Запустить проект:
```python
python3 manage.py runserver
```
Открыть в браузере: http://127.0.0.1:8000/
